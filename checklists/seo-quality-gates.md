# SEO Quality Gates

## Search intent and content
- [ ] One clear primary search intent is defined.
- [ ] The page solves the user's task before optimizing for search engines.
- [ ] Primary and supporting queries map naturally to the page.
- [ ] No obvious keyword cannibalization is introduced.
- [ ] Claims are supported by project evidence.

## On-page
- [ ] Unique, descriptive title.
- [ ] Useful meta description.
- [ ] One clear H1.
- [ ] Logical heading hierarchy.
- [ ] Descriptive internal links.
- [ ] Images have meaningful alt text when appropriate.
- [ ] URL is concise and stable.
- [ ] Canonical strategy is correct.
- [ ] Social sharing metadata is considered.

## Structured data
- [ ] Schema type matches actual page/entity content.
- [ ] Structured data contains no fabricated facts.
- [ ] Local business/NAP data is consistent where applicable.

## Technical
- [ ] Page is indexable when intended.
- [ ] robots directives are correct.
- [ ] Sitemap inclusion is correct.
- [ ] No broken critical links.
- [ ] Mobile rendering is usable.
- [ ] Performance risks are reviewed.
- [ ] Redirect/canonical conflicts are absent.

## Quality and evidence
- [ ] Brand voice/context was loaded before final copy.
- [ ] Used keywords are recorded.
- [ ] Material SEO decisions are documented.
- [ ] Validation evidence is recorded.
- [ ] Unresolved risks are explicitly reported.
- [ ] Production-ready is not claimed without evidence.
