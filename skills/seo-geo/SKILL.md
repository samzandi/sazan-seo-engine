# GEO / AEO

## Principles
- Make entities explicit and unambiguous.
- Answer important questions directly before expanding.
- Prefer attributable, verifiable facts over vague claims.
- Surface original experience, methodology, data, and limitations.
- Use clear headings, definitions, tables/lists when they genuinely improve extraction.
- Keep dates/freshness visible where time matters.
- Link claims to authoritative sources where appropriate.
- Use structured data to reinforce, not replace, visible content.

## Audit
Evaluate answerability, entity clarity, evidence density, original value, source quality, passage-level readability, freshness, and consistency between metadata/schema/body.

## Guardrail
Never optimize for AI citation by fabricating statistics, fake quotations, invented studies, or unsupported authority signals.
