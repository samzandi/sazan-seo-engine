# SEO Content Brief

## Trigger
Use for content briefs, article plans, landing-page briefs, service-page briefs, or pre-writing SEO research.

## Required context
- target topic or page purpose
- target market/language when known
- brand context from `references/`
- existing keyword registry

Do not invent missing business facts.

## Workflow
1. Load brand context and `references/used-keywords.md`.
2. Define audience, conversion goal, search intent, and page type.
3. Research the SERP when web access is available. Separate observed evidence from recommendations.
4. Select one primary query and supporting entities/questions.
5. Check cannibalization against existing pages/registry.
6. Identify competitor patterns and, more importantly, useful gaps they fail to satisfy.
7. Build title direction, meta direction, H1, H2/H3 outline, FAQ opportunities, internal-link targets, evidence requirements, and structured-data candidates.
8. Add GEO/AEO considerations: clear entity definitions, concise answer blocks, attributable facts, original experience, and source-ready claims.
9. Produce a writer-ready `BRIEF.md` style deliverable plus an evidence section.
10. Record the selected primary keyword only after the target page is approved/created.

## Output contract
- Goal and audience
- Search intent
- Primary query
- Supporting queries/entities/questions
- SERP/competitor evidence
- Differentiation/content gap
- Proposed title/meta/H1
- Detailed outline
- Internal linking plan
- Schema candidates
- E-E-A-T evidence needed
- GEO/AEO opportunities
- Conversion/CTA plan
- Risks and unknowns
- Validation checklist

## Quality gate
A brief fails if it is based only on keyword density, fabricates facts, ignores intent, or cannot distinguish evidence from inference.
