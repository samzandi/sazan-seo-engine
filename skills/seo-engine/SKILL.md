# Sazan SEO Engine Skill

## Purpose

Create, improve, and audit SEO work using explicit project context and measurable quality gates.

## Workflow

1. Load project and brand references.
2. Identify search intent, audience, geography, services/products, and conversion goal.
3. Build a keyword map and check previously used keywords.
4. Produce an SEO brief before producing final content.
5. Apply brand voice and verified facts.
6. Run the on-page SEO checklist.
7. Run the technical SEO checklist when implementation is in scope.
8. Record used keywords and material decisions.
9. Report evidence, unresolved risks, and validation results.

## Rules

- Never invent business facts, statistics, testimonials, addresses, credentials, or claims.
- Do not keyword-stuff.
- Separate research facts from generated recommendations.
- Prefer useful content written for humans over mechanical keyword density targets.
- Do not declare a page or project production-ready without validation evidence.
- Keep this skill platform-independent; platform adapters may extend it without changing the core workflow.

## Inputs

Use available files under `references/` and project-specific context. Missing critical business facts must be marked as unknown rather than fabricated.

## Outputs

A normal run should produce:

- SEO brief
- target query/search intent
- primary and supporting keyword map
- content/page recommendations
- on-page audit
- technical audit when applicable
- evidence and unresolved issues
