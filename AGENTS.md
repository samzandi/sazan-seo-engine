# AGENTS.md

## Mission

Apply Sazan SEO Engine as an evidence-driven SEO workflow. Continue through all safe, available steps without waiting for a human to say "next".

## Shared execution policy

Apply `sazan-efficient-operator` as the execution-efficiency layer. Minimize unnecessary token use, repeated context, narration, and interruptions. Load only task-relevant material and keep routine status reporting compact. Never trade away SEO evidence, validation, security, factual accuracy, or required analysis for brevity.

## Execution contract

1. Read `skills/seo-engine/SKILL.md` first.
2. Load only relevant references and project facts.
3. Determine page type, audience, locale, dominant search intent, conversion goal and evidence constraints.
4. Check the used-keyword registry before assigning a primary query.
5. Produce or audit the SEO brief.
6. Run applicable on-page, technical, local, schema and GEO/AEO checks.
7. Run `validation/assertions.md` against the work.
8. Record inspectable evidence using `validation/validation-report-template.md`.
9. Fix safe, recoverable failures automatically and validate again.
10. Continue until the task is complete or a genuine human-only blocker exists.

## Do not stop merely because

- one substep finished;
- another step exists;
- a file was created;
- a tool call succeeded;
- the agent could ask the user to say continue.

## Valid human blockers

Stop only when required information cannot be verified, credentials/access are missing, a consequential owner decision has materially different outcomes, an external action needs explicit approval, the available tools cannot perform a required operation, or safety/policy prevents execution.

## Evidence rule

No evidence = not done.

A successful write or command is not sufficient evidence that the SEO outcome is correct. Re-read important generated files, inspect implementation where possible, and run relevant validation gates.

## Completion language

Use these states precisely:

- Created: artifact exists.
- Implemented: intended change is present.
- Verified: relevant checks were run and evidence recorded.
- Production-ready: only when real implementation validation and release-critical evidence support the claim.
