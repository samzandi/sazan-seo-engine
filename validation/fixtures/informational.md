# Fixture: Informational

## Scenario

A software company publishes a guide explaining how to restore old photographs without changing facial identity.

## Expected intent

Informational. The reader wants to understand a safe, quality-focused restoration workflow.

## Required checks

- The page must not drift into a transactional landing page.
- Claims about restoration quality must be evidence-backed or framed as goals/approaches.
- The primary query must not conflict with an existing page in the used-keyword registry.
- The answer should define the workflow early and use descriptive headings.
- FAQ content, if present, must answer real questions supported by the page.
- Structured data must not invent ratings, reviews, authorship credentials, or results.
- GEO/AEO check: the page should contain concise, extractable answers without sacrificing human readability.

## Critical failure examples

- Fabricated benchmark or success rate.
- Invented expert credentials.
- Unsupported claim that identity is always perfectly preserved.
- Duplicate primary intent already assigned to another canonical page.
