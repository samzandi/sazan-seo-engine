# Sazan SEO Engine

A reusable, platform-independent SEO workflow and skill system for AI-assisted projects.

## Goals

- Build SEO briefs from structured brand and project context.
- Keep brand voice, facts, stories, opinions, and keyword history separate from generated content.
- Audit on-page and technical SEO before declaring work complete.
- Support local SEO, structured data, internal linking, metadata, and content quality checks.
- Remain usable across ChatGPT, Codex, Claude Code, and other agent workflows.

## Planned structure

- `skills/` — reusable SEO workflows
- `references/` — brand/context reference templates
- `checklists/` — SEO quality gates
- `docs/` — architecture and usage documentation

## Status

Initial scaffold in progress. No production-ready claim without evidence and validation.
